# Belief Updating with Misinformation

Replication code for "Belief Updating with Misinformation" by Lars Wittrock, Martin Strobel, and Elias Tsakas.

Paper: https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4352516

## Structure

```
data/           Raw experimental data (do not modify)
code/           R scripts for data preparation and analysis
output/
  figures/      Generated figures (.jpg)
  tables/       Generated tables (.tex)
```

## Requirements

- R (tested on 4.5.3)
- R packages: tidyr, dplyr, plotrix, stringr, anytime, ggplot2, ggsci, gridExtra, ggpubr, ggforce, stargazer, lme4, estimatr

Install all packages:
```r
install.packages(c("tidyr", "dplyr", "plotrix", "stringr", "anytime",
                    "ggplot2", "ggsci", "gridExtra", "ggpubr", "ggforce",
                    "stargazer", "lme4", "estimatr"))
```

## Replication

Set your working directory to the project root, then run the scripts in order:

```r
setwd("/path/to/this/repo")
source("code/Preparing Data.R")        # generates intermediate data
source("code/Figures and Tables.R")     # generates all figures and tables
```

Output will be written to `output/figures/` and `output/tables/`.

## Notes

- The scripts include a compatibility patch for stargazer 5.2.3 on R >= 4.2.
- All standard errors are clustered by subject unless noted otherwise.
- Figures 1-4 and 18 in the paper are design diagrams, not generated by these scripts.
