# Belief Updating with Misinformation

Replication package for *"Belief updating with misinformation: The role of prior
beliefs"* by Lars Wittrock, Martin Strobel, and Elias Tsakas.

Paper: https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4352516

## Structure

```
data/                  Raw experimental data (do not modify)
data/processed/        Cleaned datasets, generated by 00_prepare_data.R
code/
  00_prepare_data.R    Imports and cleans the raw data -> data/processed/
  run_all.R            Runs the full analysis pipeline (sources 01-03)
  01_main_results.R    Table 1; Figures 5, 6, 7, B1, B2
  02_dynamics.R        Tables B1, B2; Figures B4, B6, B7, B8
  03_treatments.R      Figures B9, B10, B11
  utils/               bootstrap, helpers, figure_helpers, derived_variables
output/
  main/                Table 1; Figures 5-7, B1-B2
  dynamics/            Tables B1-B2; Figures B4, B6-B8
  treatments/          Figures B9-B11
docs/                  Supporting documentation
```

## Requirements

R (tested on 4.5.3). Packages:

```r
# Analysis pipeline (run_all.R)
install.packages(c("ggplot2", "dplyr", "stargazer", "estimatr"))
# Data preparation (00_prepare_data.R)
install.packages(c("tidyr", "dplyr", "plotrix", "stringr", "anytime"))
```

## Replication

Set the working directory to the project root, then run:

```r
setwd("/path/to/this/repo")
source("code/00_prepare_data.R")   # build data/processed/  (run once, first)
source("code/run_all.R")           # generate every figure and table
```

To run a subset, set `run_sections` near the top of `run_all.R` (e.g.
`c("tab_1", "fig_5")`, or `"figures"` / `"tables"`). Each analysis file can
also be sourced on its own — it auto-loads the utilities via `utils/bootstrap.R`.

## Notes

- Each bias figure is a TikZ snippet (`.tex`) meant to be `\input{}` into the
  paper. Multi-panel figures (B4, B6–B8, B9) are a single `.tex` laying the
  panels out in a `subfigure` grid (needs the `subcaption` + `graphicx`
  packages). The TikZ figures contain the observed data bars only; the
  model-prediction curves are added by hand at the `% ADD THEORY CURVE` marker.
- Figure B1 is a scatter plot, produced as a `.jpg`.
- Standard errors in Table 1 are clustered by subject.
- `code/utils/bootstrap.R` applies a compatibility patch for stargazer 5.2.3
  on R ≥ 4.2.
- **`docs/experimental_design.md`** — experimental design, treatments, and
  processed datasets.
- **`docs/known_issues.md`** — where the code intentionally differs from the
  printed paper (Tables B1, B2, and a standard-error typo in Table 1).
- **`docs/exploratory_analyses_archive.md`** — analyses produced during the
  revision but not included in the final paper.
- **`docs/bayesian_updating_logic.md`** — technical reference for the
  belief-updating variables.
