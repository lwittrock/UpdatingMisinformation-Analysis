## Project Structure

```
data/               Raw experimental data (do not modify)
data/processed/     Cleaned datasets generated by Preparing Data.R
code/               R scripts
output/
  regular/          Regular signals / background results
    figures/
    tables/
  retract/          Retraction results
    figures/
    tables/
  confirm/          Confirmation results
    figures/
    tables/
```

- `code/Preparing Data.R` -- imports raw CSVs, cleans/transforms data, saves `.rda` and `.csv` files to `data/processed/`. **Must run first.**
- `code/Figures and Tables.R` -- generates all figures and regression tables. Loads `.rda` files from `data/processed/`. Organized into 3 topic sections: Regular Signals, Retractions, Confirmations.

## How to Run

1. Open this folder in VS Code
2. Set working directory to project root
3. `source("code/Preparing Data.R")` -- creates cleaned datasets in `data/processed/`
4. `source("code/Figures and Tables.R")` -- generates figures and tables in `output/`

## Configuration

- `data_path` / `processed_path` in Preparing Data.R -- relative paths from project root
- `inpath` in Figures and Tables.R -- path to processed data
- `outpath` -- base output directory; topic subfolders created automatically
- `fig_path(topic, name)` / `tab_path(topic, name)` -- helper functions for output paths
- `output_type` -- `"latex"` or `"html"` for table output format
- `set_dpi` -- figure resolution (default 400)
- `fig_width` / `fig_height` -- shared figure dimensions (default 7.5 x 5 inches)

## Running specific sections

`run_sections` on **line 20** of `Figures and Tables.R` controls which sections execute. Options:
- `"all"` — run everything (default — reset to this before committing)
- `"figures"` / `"tables"` — category filter
- `c("fig5", "tab3", "tab_conf_inf", ...)` — specific sections by name

Section names match the `.should_run("...")` guards in the code. Dependencies are resolved automatically via `.deps` list (line 172).

## Key Variables Reference

### Confirmation variables:
- `over_report`: belief - Bayesian posterior (standard)
- `over_report_conf_alt`: belief - induced posterior (alternative)
- `post_induced`: posterior using induced urn distribution
- `urn_dist_induced`: urn distribution that rationalizes t-2 -> t-1 beliefs
- `confirm_irrational`: flag for urn_dist outside [0,1]
- `signal_confirm`: signal strength implied by induced posterior
- `initial_reaction_conf`: reaction category with "over much" split
- `belief_change_rational_lag1`: Bayesian benchmark belief change
- Note: `over_report` sign convention differs -- retractions use `-over_report`, confirmations use positive

### Prior bin convention:
- All prior bin analyses use **signal-aligned priors** (`prior_aligned`): for red signals use belief as-is, for blue signals flip to `1-belief`
- Bins are non-overlapping: "0-10", "11-20", ..., "91-100". Reference group = "41-50"
- Shared constants: `prior_bin_breaks`, `prior_bin_labels`, `prior_bin_ref` defined at top of Figures and Tables.R
